# C346 Lesson 09

Simple list exercises using the patterns from the Week 05 slides.

- `Exercise1.js`: FlatList showing the alphabet from a to z.
- `Exercise2.js`: SectionList showing vowels and consonants up to s, with skyblue and khaki headers.

## Run

Start the Android emulator, then run:

```sh
npm install
npm run android
```

`App.js` contains Exercise 1 and runs on its own. To run Exercise 2, copy the contents of `Exercise2.js` into `App.js`.

## Check

```sh
npx expo lint
npx tsc --noEmit
```

## Submission

Submit only `Exercise1.js` and `Exercise2.js` to PoliteMALL. Each exercise can also be copied into `App.js` in a blank Expo project and run on its own.
